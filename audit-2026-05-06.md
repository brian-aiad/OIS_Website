## Open Questions for Brian

1. **`aggregateRating` in schema**: The task asks to add `ratingValue: 4.9, reviewCount: 85` to InsuranceAgency schema for star snippets. SKILL.md says not to (Google's docs say aggregateRating is for review aggregator sites). The current 4.9★ from Google Business Profile will show in Maps/Local Pack without schema. For organic search star snippets, schema would need to match a verifiable source Google can cross-reference. Recommendation: **skip for now** until the domain has more authority. Google often ignores self-reported aggregateRating on local business sites.

2. **`storefront.png` → WebP**: Converting the hero background image from PNG (229KB) to WebP (est. 80–100KB) would improve LCP. This is a brand asset — confirm before converting.

3. **`logo-badge.png` → WebP**: 385KB PNG logo. Converting to WebP could save 60–70% (est. 115KB). Visual brand asset — confirm before converting.

4. **Vercel Speed Insights**: Adding `@vercel/speed-insights` would give RUM data for CWV as traffic grows, and populate the GSC Core Web Vitals report. One line in `main.tsx`. Ask before adding.

5. **`/services` content depth**: The services page has only ~368 words visible in the initial render because it's tab-based. Google executes JS and can read all tab content, so this is probably fine. But if you want to be safe for non-JS crawlers or improve perceived depth, consider adding a brief intro paragraph (2-3 sentences) above the tabs that Google indexes as static text.
